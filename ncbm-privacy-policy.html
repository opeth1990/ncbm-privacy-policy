개인정보처리방침

네이버 카페용 차단 매니저 - NCBM (이하 "본 확장 프로그램")

본 확장 프로그램은 사용자의 개인정보를 중요하게 생각하며, 관련 법령 및 Chrome Web Store 정책을 준수합니다.

1. 수집하는 정보

본 확장 프로그램은 사용자의 이름, 이메일, 연락처, 계정 정보 등 개인 식별 정보를 수집하지 않습니다.

본 확장 프로그램은 사용자의 브라우징 기록을 외부 서버로 전송하지 않으며, 사용자의 동의 없이 데이터를 수집하지 않습니다.

2. 저장되는 정보

본 확장 프로그램은 차단 기능을 제공하기 위해 사용자가 직접 설정한 정보만 저장할 수 있습니다. 예를 들면 다음과 같습니다.

  • 차단 명단
  • 키워드 필터
  • 등급 설정
  • 기타 사용자가 직접 입력하거나 변경한 설정값

이 정보는 사용자의 브라우저 로컬 저장소(chrome.storage.local)에만 저장되며, 외부 서버로 전송되지 않습니다.

3. 정보의 이용 목적

저장된 정보는 다음 목적에만 사용됩니다.

  • 네이버 카페 페이지에서 차단 대상 항목을 숨기거나 표시하지 않기
  • 사용자가 지정한 차단 규칙을 유지하고 불러오기
  • 확장 프로그램의 설정 상태를 보존하기

4. 제3자 제공

본 확장 프로그램은 사용자의 정보를 외부 서버로 전송하지 않으며, 제3자에게 판매, 공유, 제공하지 않습니다.

5. 권한 사용 목적

본 확장 프로그램은 기능 제공에 필요한 범위에서만 권한을 사용합니다.

  • host_permissions (cafe.naver.com/*): 네이버 카페 페이지에서 차단 대상 항목을 숨기거나 표시하지 않기 위해 사용합니다.
  • storage: 사용자가 설정한 차단 정보와 옵션을 로컬에 저장하고 불러오기 위해 사용합니다.
  • tabs: 현재 활성 탭의 카페 ID를 확인하고, 확장 프로그램 아이콘 및 배지를 갱신하기 위해 사용합니다. 탭 URL 외에 다른 정보에는 접근하지 않습니다.

6. 데이터 보관 및 삭제

저장된 설정은 사용자의 브라우저에 보관됩니다. 사용자가 확장 프로그램을 삭제하거나 저장 데이터를 지우면 해당 정보도 함께 삭제됩니다.

사용자는 확장 프로그램의 설정 초기화 또는 브라우저의 저장 데이터 삭제를 통해 저장된 정보를 제거할 수 있습니다.

7. 아동의 개인정보

본 확장 프로그램은 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 정책 변경

본 개인정보처리방침은 서비스 변경, 법령 변경, 또는 Chrome Web Store 정책 변경에 따라 수정될 수 있습니다. 변경 시 본 페이지에 최신 내용을 게시합니다.
